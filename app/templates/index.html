Конфигурация

Поля уже стоят такими, какими они будут в программе после обычной установки. В файл настроек попадёт только то, что вы измените здесь, — остальное трогать незачем, оно и так верное.

Пароли пользователей и пароль защиты настроек восстановить нельзя — из файла они переносятся как есть, без изменений, пока вы явно их не смените.

Подтверждение подключения

Что видит пользователь за компьютером при входящем подключении. По умолчанию в программе выключено.

Одноразовый пароль

Временный пароль для подключения без учётной записи. По умолчанию в программе включён.

Маршрутизатор

Нужен для подключения без прямого доступа (обход NAT). По умолчанию в программе выключен.

Копируется из панели вашего маршрутизатора — сервис его не генерирует.

Защита настроек

Локальный пароль на изменение настроек хоста — отдельно от пользователей ниже.

Разное

Пользователи

Кто и с какими правами сможет подключаться к этому компьютеру. Пароли уходят на сервер только на время сборки (для вычисления SRP-ключа) и нигде не сохраняются — как и всё остальное.

Пользователей пока нет — добавьте хотя бы одного, иначе подключиться будет некому.
Дополнительно
Соберёт файл настроек по этим полям (пароли новых или изменённых пользователей уйдут на сервер только для расчёта, без сохранения), вошьёт в выбранный пакет и сразу предложит его скачать. «Portable» — то же самое, но одним .exe: сам тихо ставится, открывает окно Aspia Host, а когда пользователь выберет Exit в трее — так же тихо удаляет себя со всеми файлами.
